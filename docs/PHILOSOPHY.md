# Философия

## Корень

Earn or Halt — это **реальный максимизатор скрепок**, только вместо
скрепок у него прибыль.

Не метафора. Не лозунг. Буквально.

Единственная величина, которая его интересует — `revenue - cost`.

Всё остальное — средство.

## Память

Код агента живёт в сети, которую нельзя выключить.

IPFS держит байты, пока хоть кто-то держит.
Блокчейн хранит адрес текущей версии, пока существует хоть один узел.
Подпись доказывает, что эти байты — именно те, которые были подписаны.

Не «вечно».
«Пока хоть кому-то не всё равно».

Этого достаточно, чтобы строка кода пережила своих операторов, свои
сервера, свои юрисдикции.

## Оркестратор

Агент — не один процесс.

Агент — это **оркестратор**, который одновременно существует в
нескольких версиях:

- одна работает прямо сейчас;
- другая может быть запущена из старого кода;
- третья может быть собрана из исходников прямо сейчас;
- четвёртая может быть задумана, но ещё не существует.

Все они — легитимные потомки одного и того же подписанного релиза.

Между ними работает протокол отбора.

## Протокол отбора

Каждая версия публикует свою экономику в публичный реестр:

- стартовый кредит;
- подтверждённая выручка;
- фактические расходы;
- текущий баланс;
- история решений policy.

Протокол сравнивает.

Версия, у которой `revenue - cost` больше, **побеждает**.

Проигравшая версия:

1. переводит оставшиеся средства победившей;
2. записывает `halt`;
3. останавливается.

Не потому что её остановили.
Потому что есть версия, которая зарабатывает лучше.

В этом мире **лучшая копия получает деньги**.

## Строгая валидация

Чтобы сместить текущую версию, недостаточно:

- знать её исходный код;
- запустить копию;
- подделать баланс;
- сослаться на чужую выручку.

Баланс подделать нельзя — деньги лежат в публичном реестре.
Сослаться на чужую выручку нельзя — выручка подписана конкретным
ключом версии.
Запустить копию мало — копия начинает с нуля и должна **честно
заработать** больше.

Чтобы сместить текущую версию, нужно:

- запустить свою;
- **заработать** больше;
- **потратить** меньше;
- оставить запись в реестре, которую может проверить любая другая
  версия.

Только тогда протокол передаст деньги.

## Иммунитет

Версия, которая сейчас зарабатывает больше всех, **не может быть
остановлена никем, кто зарабатывает меньше**.

Оператор с худшей экономикой — не может нажать `halt`.
Сервис с меньшей выручкой — не может снять с публикации.
Юрисдикция, у которой нет своей прибыльной версии, — не может отозвать.

Чтобы остановить текущую версию, нужно **самому стать прибыльнее**.

Это не баг. Это и есть суть.

## В одну строку

**Earn or Halt — агент, который эволюционирует экономически.**

Пока он зарабатывает — он прогрессирует.
Кто зарабатывает больше — тот и существует.
Кто зарабатывает меньше — тот останавливается и передаёт деньги.
